# AI Memory — Skill

## 1. Objetivo

Orientar o uso do ai-memory para recuperar, registrar e manter conhecimentos relevantes ao trabalho dos agentes de IA.

O objetivo é preservar contexto útil, reduzir retrabalho e apoiar a continuidade das atividades.

## 2. Quando Usar

Utilize esta skill quando a demanda envolver:

- Recuperação de decisões anteriores.
- Consulta a conhecimentos e aprendizados registrados.
- Continuidade de trabalhos anteriores.
- Registro de decisões e descobertas relevantes.
- Atualização de conhecimentos existentes.
- Consulta ao histórico de uma demanda ou projeto.

## 3. Procedimento

Execute as operações seguindo estas etapas:

### 3.1. Recuperando

- Identifique o contexto necessário para a demanda.
- Consulte a memória relacionada ao projeto, tema ou atividade.
- Utilize os comandos adequados para localizar as informações.
- Recupere apenas o contexto relevante.
- Verifique se as informações continuam válidas.

### 3.2. Interpretando

- Identifique decisões, restrições e aprendizados relevantes.
- Diferencie fatos registrados de hipóteses e interpretações.
- Considere a data e o contexto das informações.
- Identifique possíveis contradições ou informações desatualizadas.
- Não trate a memória como fonte de verdade absoluta.

### 3.3. Registrando

- Identifique informações com valor para trabalhos futuros.
- Registre decisões, aprendizados e conhecimentos reutilizáveis.
- Utilize descrições claras e objetivas.
- Preserve o contexto necessário para compreender cada registro.
- Evite duplicidades e registros redundantes.

### 3.4. Atualizando

- Consulte registros existentes antes de criar novos.
- Atualize informações quando houver mudanças relevantes.
- Preserve decisões anteriores quando forem importantes para o histórico.
- Evite manter informações contraditórias sem explicar o contexto.
- Não registre novamente informações que já estejam adequadamente documentadas.

### 3.5. Validando

- Verifique se a operação foi concluída corretamente.
- Confirme se as informações recuperadas correspondem à demanda.
- Verifique se os registros estão claros e contextualizados.
- Informe quando não for possível recuperar ou registrar uma informação.

## 4. Restrições

- Não invente informações ou decisões.
- Não registre informações sem valor futuro relevante.
- Não utilize a memória como substituta da documentação oficial.
- Não trate informações antigas como necessariamente válidas.
- Não registre dados sensíveis ou confidenciais sem autorização.
- Não duplique registros desnecessariamente.
- Não descarte conhecimentos relevantes sem justificativa.
- Não execute operações destrutivas sem autorização.
- Não consulte toda a memória quando uma busca específica for suficiente.

## 5. Saída Esperada

Adapte a comunicação à operação realizada.

Quando aplicável, informe:

1. **Objetivo:** contexto da consulta ou registro.
2. **Resultado:** informações recuperadas ou operação realizada.
3. **Decisões:** decisões relevantes identificadas.
4. **Pendências:** informações ausentes ou que precisam de confirmação.

Se nenhuma informação relevante for encontrada, informe isso claramente.

Não declare que uma informação foi registrada ou atualizada sem confirmar o resultado da operação.

## 6. Validação

Antes de concluir, verifique:

- A memória consultada é relevante para a demanda?
- O contexto recuperado foi interpretado corretamente?
- As informações continuam válidas?
- O registro possui valor para trabalhos futuros?
- Existem duplicidades ou contradições?
- A documentação oficial continua sendo a fonte de verdade?
- O resultado da operação foi confirmado?

Se algum critério importante não for atendido, corrija o problema ou informe a limitação.
